# 游戏系统
成长：永久经验、六属性（力量、智慧、活力、心灵、善意、探索）。人类GK→发现神光棒→复合型→强力/空中/复合掌握→闪耀迪迦；非终点，继续等级、技能、称号、动画与纪念品。固定人类外观，可解锁服饰。每类每日20XP为待平衡暂定值；账本去重；光之碎片独立可消费，无真实货币。商店轮换但物品回归，重要形态靠成长解锁。短期奖励数天至两周，长期数周至数月；即时反馈，无负面反馈。
小屋：初始有床、书桌、电脑、书架、吉他、飞镖、沙发、CRT、植物、迪迦角；后续书房、健身房、庭院、观测台、纪念馆。家具编辑模式拖动、等距网格吸附、旋转、收纳、碰撞、自动保存。GK自主生活、点击寻路、物件互动；真实记录可联动但无记录也正常生活。昼夜季节、可选场景时间；BGM/环境音/音效独立调节。宠物含真实动物与友善生物，无饥饿死亡惩罚。
探索：场景式非开放世界，初始3–5个精细场景为规划范围；自由探索，无体力、GPS或运行时AI依赖。地图、原创故事、随机遭遇、调查线索谜题隐藏区、可选叙事战斗、收藏怪兽图鉴六层。战斗为剧情选择和变身技能演出，无操作策略战斗或失败惩罚。时间天气变化、事件连续性、隐藏触发、配置化扩展。内容数量待实际制作评估。
纪念馆：光之荣誉馆、人生纪念馆、时光长廊；自动与手动记忆、照片、愿望星图、未来信件、灵感笔记。
