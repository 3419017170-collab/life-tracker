# GK · 光之力量 V2.0 产品规范
状态：根据总控对话已确认决策整理；细节待验收。
目标：真实生活的正反馈游戏，而非带经验条的打卡网页。现代现实世界，GK为普通人，可变身迪迦。只做迪迦主线，不加入其他奥特曼。移动端优先，五个入口：小屋、探索、记录、档案、角色。
原则：无惩罚、无强制签到、无连续打卡奖励、无生活总分；休息不造成损失。两周是阶段目标，可延期，品质优先。
生活记录：主动成长（建设身体、获得新知、有所突破、勇敢行动、传递善意）；感受生活（出去转转、享受兴趣、与人联结、善待自己、发现美好）。一键记录、可选备注、自动跨日、历史查看、专业记录联动且去重。
专业管理：体重目标215→180斤；体重、腰围、体脂、肌肉、照片、饮食、睡眠、心率、情绪；训练逐组记录、重量、休息计时、历史与PR；科研成长与行政时间分开。可选计划、自定义习惯。日常/专注/训练/休养/自由模式不改变奖励。情绪、精力、身体、专注分别五级自评，可不填，与客观数据分离，不关联奖励。趋势7/30/90天及全部；周/月/年报告，专业趋势与成长纪念双轨，支持导出。灵感记录非日记。健康自动同步暂缓。
