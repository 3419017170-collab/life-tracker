# GK · 光之力量 V2.0 独立测试版

这是一个无第三方依赖的静态页面，位于 `test/v2/`。仓库根目录的 V1 页面、清单、图标和离线脚本保持原样。

## 本地预览

在仓库根目录启动任意静态 HTTP 服务，然后打开 `/test/v2/`。例如：

```powershell
python -m http.server 8765
```

本地预览地址为 `http://localhost:8765/test/v2/`。页面使用浏览器本地存储；本地预览与线上站点属于不同来源，因此不会自动读取线上浏览器数据。需要体验旧版迁移时，可先在 V1 导出 JSON，再在 V2 的「报告与备份」中导入。

## 数据与兼容

- 在与 V1 相同的网站来源下，首次打开时会读取 `life-feedback-v1` 并复制到 V2；旧版键不删除、不改写。
- V2 记录和奖励账本使用 `gk-light-v2`。同一天同一项光之记录只奖励一次，改写备注不会再次发放 XP。
- 导出的备份包含生活与身体记录，请由用户自行保存。页面不调用第三方分析、字体或数据服务。
- V2 离线缓存和服务工作线程限定在 `test/v2/` 路径，不清理 V1 的缓存。
